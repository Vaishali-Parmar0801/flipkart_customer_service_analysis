# Flipkart Customer Service Analysis

## 🔍 Overview
Analysis of customer service data to evaluate performance and satisfaction levels.

## 🎯 Objective
- Identify common customer complaints
- Measure resolution time
- Improve customer satisfaction

## 🛠 Tools Used
- Excel

## 📈 Key Insights
- Majority complaints related to delayed delivery
- Resolution time improved over months
- High satisfaction in resolved cases

## 🚀 Outcome
Provided insights to improve customer service efficiency.
